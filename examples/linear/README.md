# Linear example

A compact, independent educational example filled from Linear's public material, checked **5 October 2026**. It shows how the templates work for a recognizable brand.

**Confirmed** means supported by the linked public source. **Proposed** covers this example's interpretations and writing choices. **Unknown** identifies gaps. These are six filled templates; the other templates are unnecessary for this example task.

| Read | What it demonstrates |
|---|---|
| [Brand core](identity/brand-core.md) | A short product explanation and proposed pitch |
| [Voice guide](identity/voice-guide.md) | Public examples translated into practical writing rules |
| [Audience](identity/audience-profile.md) | Useful hypotheses without invented customer quotes |
| [Guardrails](guardrails/guardrails.md) | A short, consistent publishing check |
| [Website](channel/website.md) | Published copy separated from a new draft |
| [Product and proof](proof/product-and-proof.md) | Sourced product facts, dated pricing, and honest gaps |

Try a task:

```text
Read this example's identity files, guardrails, website, and product-and-proof.
Draft a 60-word website section explaining how projects organize product work.
Follow the proposed voice rules. Use only Confirmed product facts.
Label the result Draft and list any claim that needs review.
```

Use this as a format reference when filling your own brand. Sources stay beside the relevant content. Linear names and quoted material retain their original ownership.
